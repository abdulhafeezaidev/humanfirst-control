1) PROJECT OVERVIEW
==================================================
Project name: HumanFirst Control

What it does:
HumanFirst Control is an ethical AI-usage control platform for education. It is designed for exam/focus enforcement with policy-based allowlisting (apps/domains) while explicitly avoiding surveillance-style monitoring.

Primary goals:
- Enforce institution-defined exam/focus policies in a transparent way.
- Restrict disallowed apps and domains during active policy windows.
- Provide admin governance (policy lifecycle, audit logs, metrics, invitations, role management).
- Provide student transparency (what is restricted, why, and when).
- Support assignment mode with browser + editor risk telemetry.
- Operate as a pilot-ready system for schools/institutions.

Stated ethical boundaries (from docs/readme):
- No keystroke logging.
- No screen recording.
- No content reading/spying.
- No AI-cheating accusations.
- Enforcement-first, not surveillance.

Current maturity:
- Pilot-ready v0.1 according to repository documentation.
- Real code exists across web app + Supabase backend + Windows agent + Electron desktop wrapper.
